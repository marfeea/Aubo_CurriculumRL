# CurriculumRL 工程规范

## 建立事实基线

1. 在修改前运行 `git status --short`，并检查目标文件的现有 diff；把未提交内容视为用户改动，不覆盖、不回退。
2. 使用 `rg --files` 和 `rg` 确认真实文件布局、调用方和配置来源，不依赖模板路径猜测。
3. 涉及迁移语义、TCP 契约、Differential IK 或课程设计时，先读取 `docs/DifferentialIK课程RL_TCP停靠方案与项目迁移说明.md` 的相关章节。
4. 明确本次变更的事实来源、公共接口、验证层级和不在范围内的内容，再开始编辑。

## 保持工作区边界

- 将仓库根目录视为命令与文档入口，将 `source/CurriculumRL/CurriculumRL/` 视为 Python 产品代码根目录。
- 在产品代码根目录内按职责组织 `configs/`、`logic/`、`runtime/` 和 `tasks/tcp_docking/`；在迁移代码落地前，不为旧模板任务名建立隐式兼容入口。
- 将仓库级执行入口保留在 `scripts/`，将设计与验收事实保留在 `docs/`，将测试放在仓库可发现且未被忽略的位置。
- 迁移说明给出的目录是目标职责边界；实际新增路径必须同时满足 Python 包结构和现有 Isaac Lab 扩展布局。

维持以下单向依赖：

```text
配置 -> 纯逻辑 -> Isaac 适配/执行 -> 训练与生成数据
```

- 配置只保存资产契约、参数和不可变任务真值，不包含场景查询或训练副作用。
- 纯逻辑通过显式输入完成 TCP 数学、姿态、停靠状态机和课程统计，不导入 Isaac、SB3 或文件写入设施。
- Isaac 适配层解析场景实体、读取张量并写入执行目标；不要把任务真值复制到适配器。
- 任务模块组装动作、观测、事件、奖励、终止和课程更新；避免反向导入与循环依赖。
- 数据、日志、渲染和 Checkpoint 只能消费上游状态，不得反向决定任务逻辑。

## 固定控制器与任务语义边界

- 将六维 TCP 增量、Jacobian 解析、阻尼最小二乘、关节限位投影和关节目标写入明确放在 Differential IK 动作适配链中。
- 不引入 Lula URDF、robot description、求解器或其诊断流程作为新方案运行依赖；旧 Lula 方案只作为对照基线。
- 将 TCP 标定、坐标系、四元数顺序、最终成功阈值和安全阈值保持为单一事实来源。
- 将课程等级、晋级/回退阈值、训练采样分布与正式评估阈值分开配置。课程只能改变训练难度、辅助奖励或约束启用顺序，不能静默改变最终任务真值。
- 让最终成功奖励与统一停靠状态机绑定；不要用课程阶段成功替代正式停靠成功。

## 控制改动质量

- 使用 UTF-8；新增项目注释和面向维护者的说明优先使用中文，标识符遵循现有 Python 风格。
- 只修改实现目标所需的行，避免无关格式化、批量重排或整文件改写。
- 一个模块只承担一个清晰职责；当配置、纯逻辑、Isaac 访问和数据输出混在一起时先拆分边界。
- 修改公共函数、配置字段、任务注册名或张量形状前，查找全部调用方并说明兼容策略。
- 诊断输出必须可关闭；至少保留启动参数、资产解析、控制器输入/输出和写入失败的上下文，但不得在正常训练中逐步刷屏。
- 不把 Checkpoint、日志、视频、数据集或临时渲染产物提交为源码。训练运行必须能关联任务名、课程等级、随机种子、运行标签和配置快照。
- 若新增产物目录，先核对并更新 `.gitignore`，再运行训练或生成数据。

## 分层验证

按风险从低到高执行实际可用的验证，不把“未运行”写成“通过”：

1. 检查 `git diff --check` 和目标 diff，确认无用户改动丢失、无意外文件和无旧绝对路径。
2. 对 Python 改动运行 `python -m compileall source/CurriculumRL/CurriculumRL scripts`。
3. 环境提供 Ruff 时运行 `python -m ruff check source scripts` 和 `python -m ruff format --check source scripts`。
4. 存在相关测试时运行最小目标测试，再按风险扩大到 `python -m pytest`；没有测试时明确记录缺口。
5. Isaac Lab 环境可用时运行 `python scripts/list_envs.py`，并运行本次任务对应的环境 smoke test、零动作或随机动作短回合。
6. 只有实际启动仿真并观察到结果后，才报告 Isaac 场景、张量或控制器验证通过。

## 交付结果

报告以下内容：

- 修改的文件与行为变化；
- 保持不变的任务真值和公共契约；
- 已执行命令及结果；
- 未执行的 Isaac/训练验证及原因；
- 遗留风险，尤其是资产、TCP 标定、Jacobian 索引和课程评估隔离风险。
