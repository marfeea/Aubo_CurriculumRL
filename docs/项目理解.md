# CurriculumRL 项目理解

本文沉淀跨阶段可复用的机理结论。设计真值仍以 `DifferentialIK课程RL_TCP停靠方案与项目迁移说明.md` 为准，阶段是否通过以对应施工记录为准。

## IK 求解与执行器刚度/阻尼的职责差异

### 核心结论

上一个 Lula IK 项目需要机械臂刚度 `6000`、阻尼 `600` 才能获得较高 TCP 跟踪精度，并不表示 Lula 的数学解只有在高增益下才准确。它表示“Lula 生成的关节位置目标”经过 Isaac 隐式位置执行器和物理系统后，需要足够强的关节伺服才能让实际关节紧跟目标。

当前 Differential IK 同样不能绕过执行器。区别在于它每个物理周期读取当前 Jacobian 和关节状态，重新计算小关节增量，并经过单步、速度和位置限幅后写入目标。高频闭环重算能够持续修正未完成的运动，因此对单次 IK 解被精确执行的依赖更低，但最终物理跟踪精度仍受相同的执行器刚度、阻尼、惯量、接触和仿真步长影响。

### 机理拆分

1. **IK 求解层**
   - Lula IK：非线性 IK 根据目标位姿产生关节构型；求解精度描述目标构型在运动学模型中的误差。
   - Differential IK：根据当前 Jacobian 和六维位姿误差产生局部关节增量；阻尼、奇异保护和步长限制决定局部更新的稳定性与速度。
2. **关节目标层**
   - 两者最终都向 articulation 写关节位置目标。
   - Lula 路线更接近“求出一个关节目标，再由伺服器追踪”；当前 Differential IK 是“每个物理周期基于实际状态重新修正目标”。
3. **执行器与物理层**
   - 刚度决定位置误差产生多强的恢复力矩；阻尼抑制速度和高刚度带来的振荡。
   - 刚度过低会产生稳态滞后，阻尼不足会超调或抖动，阻尼过大则响应迟缓。`6000/600` 是执行器跟踪参数，不是 IK 算法参数。
4. **任务精度层**
   - 数学 IK 误差、实际关节跟踪误差、TCP 标定误差和最终停靠成功率是四个不同指标，不能互相替代。

### 当前项目映射

- 执行器基线仍保持机械臂刚度 `6000`、阻尼 `600`，阶段 C 没有调参，因此当前结果不能证明 Differential IK 在更低增益下仍保持同等精度。
- 仿真频率为 `120 Hz`，策略频率为 `4 Hz`，策略增量目标在 `30` 个物理步内保持；Differential IK 每个物理步重新求解并写关节位置目标。
- 常规 DLS 阻尼为 `0.05`；最小奇异值低于 `0.05` 时切换为 `0.20`。
- 单物理步关节增量上限为 `0.02 rad`，等效上限 `2.4 rad/s`，比全局 `3.14 rad/s` 速度限制更严格；位置目标距硬限位保留 `1°` margin。

### 验证状态

- 阶段 C 已验证十二个正负单轴方向、固定位置和固定六维小目标收敛、四环境隔离以及保护触发。
- 固定位置残差约 `4.5 mm`；固定六维综合残差约 `0.00238`，该值混合米和弧度，不能直接解释为毫米。
- 零动作 30 个物理步 TCP 平移漂移约 `1.1 mm`。
- 四个真实目标状态目前只验证向 preposition 接近，尚未证明完整停靠状态机成功。

### 风险与后续验证

- TCP 偏置 `(0.0, -0.12, 0.102) m` 仍为近似标定，会限制真实 TCP 精度。
- 当前 DLS 阻尼在奇异阈值处硬切换，训练分布频繁跨阈值时可能出现控制不连续。
- 若要比较 Lula 与 Differential IK 对执行器增益的依赖，必须固定场景、目标、控制频率和成功判据，对 `6000/600` 及更低增益做独立消融；在完成该实验前，不应声称 Differential IK 可以降低刚度或阻尼。
