## 施工边界

- 保持 `curriculum-v2-p3` 的 52 维观测、六维动作、`0.02 m / 5°` 动作尺度和 checkpoint 三件套契约，不让 P5 破坏阶段 1 策略继承。
- L1 使用既有六维全开动作掩码；训练时 `previous_level_sampling_probability=0.25`，使 25% episode 回归到 L0 的平移-only 动作与阶段 1 成功口径，其余 episode 使用 L1 位姿口径。这是本版的 episode 级渐进释放，不引入隐藏的连续动作尺度。
- L1 继续固定 `state_01`、三个路径模式和 C1；阶段成功为 `d_pos ≤ 0.06 m`、`e_rot ≤ 20°`、`v_tcp ≤ 0.06 m/s`、连续 2 个策略步并已到达路径参考点。正式停车成功仍由统一停车状态机独立给出。
- 姿态塑形沿用已接线的姿态误差观测、工具轴进展、停车区姿态/速度质量和低速保持分量；P5 不修改最终奖励、TCP 标定、Jacobian、DLS、关节保护或控制频率。

## 新增入口

- `scripts/smoke_stage2.py`
  - 固定 L1、`state_01` 和三个路径模式；
  - 验证旋转动作通过 `5°` 标度实际进入 Differential IK；
  - 先到达各模式参考点，再用小幅旋转探针确认姿态误差下降；
  - 检查 52 维观测、C1 七个过滤接触张量、奖励有限值及四类控制器保护统计；
  - 该入口是接口/控制链 smoke，不把手写动作当成阶段 2 策略或 G5 证据。
- `scripts/evaluate_stage2_worker.py`
  - 每个进程只运行一个 `L1/L0 × policy × seed × z` 固定单元；
  - 支持零动作、随机动作和冻结 PPO；
  - PPO 继续强制 checkpoint、`VecNormalize` 和课程状态 JSON 三件套版本一致；
  - 保存每 episode 初末位置/姿态误差、误差改善、速度、两种成功、安全、超时、奖励分量和 TCP 轨迹；
  - 记录动作分量饱和率、四类保护触发率、最大连续保护步数及实际关节限位越界量。
- `scripts/evaluate_stage2.py`
  - 默认同时调度 L1 位姿能力和 L0 固定回归；
  - 按路径模式统计成功、安全、位置/姿态改善和成功轨迹簇；
  - 输出只标记为 G5 人工审查证据，不自动宣称门禁通过。
- `logic/stage_p5_evaluation.py` 与 `tests/test_stage_p5_evaluation.py`
  - 固化双层评估矩阵、结果命名、能力分组和 P5 配置不变量。
