# CurriculumRL 能力课程设计

版本：`v0.4-p0`  
日期：2026-07-17  
状态：P0 决策已冻结；尚未接入训练行为  

本文是后续课程方案修改的统一设计入口。课程等级、碰撞分组、阶段成功指标和切换规则先在本文修订并记录版本，再同步到 `configs/curriculum.py`、任务配置、测试和施工记录。当前代码行为仍以仓库配置为准，本文中的暂定数值不代表已经完成 Isaac 动态验证。

## 1. 课程目标与职责边界

课程按以下能力顺序展开：

1. 同一起点、同一终点的位置到达与多路径分布；
2. 同一起点、同一目标位姿的多路径位姿到达；
3. 多目标初始化下的任务内泛化；
4. 完整碰撞约束下的避障与能力保持；
5. 完整任务下的末端精确对齐、低速进入和稳定停靠。

策略输出机器人根坐标系下的六维 TCP 增量。Differential IK 负责在每个物理步把 TCP 增量目标转换为受限关节目标；策略则可以从状态—动作—回报分布中学习可达性、冗余构型、奇异区域、路径模式和动作序列等运动学结构。二者不是互斥关系：控制器提供局部求解与安全投影，策略学习跨时间、跨状态的运动学与任务分布。

阶段 1/2 的能力名称分别使用“位置到达策略”和“位姿到达策略”，但保留 positionIK/poseIK 作为面向课程目标的简称，不把它们解释为重新训练 Differential IK 求解器。

## 2. 固定接口与跨阶段继承

- 动作接口从阶段 1 起固定为六维 TCP 增量；当前尺度为单策略步最大 `0.02 m` 平移和 `5°` 旋转。位置阶段通过动作掩码或固定参考姿态限制旋转，不改变动作张量形状。
- 观测形状从阶段 1 起固定。路径模式、碰撞组距离等后续所需字段应从第一阶段预留，通过掩码或零填充控制启用，避免升级时破坏 checkpoint。
- PPO 模型、优化器、`VecNormalize`、课程窗口和课程配置版本共同继承；每个 episode 保存自己的课程等级、目标状态、路径模式和碰撞组版本。
- 升级后保留上一等级的回归采样，防止新增姿态、目标或碰撞能力覆盖已学的位置到达能力。
- 当前 `120 Hz` 仿真、decimation `30`、`4 Hz` 策略频率和 `40 s` episode 基线在课程论证阶段保持不变。

## 3. 同一起终点多路径定义

### 3.1 能力定义

多路径明确指：在相同机器人初始关节状态、相同 TCP 起点、相同目标位置或位姿下，策略能够产生两条以上几何上可区分且都满足阶段成功条件的轨迹。

在无障碍空间中只能称为“几何轨迹多样性”，不能声称存在不同同伦类；引入障碍后，才进一步按障碍两侧、上/下方等拓扑关系定义同伦路径模式。

### 3.2 策略表达

相同完整观测下的确定性策略只能输出同一动作。为使多路径可复现，默认方案是在每个 episode reset 时采样离散路径模式 `z`，把 `z` 作为策略观测的一部分；同一物理起终点在不同 `z` 下产生不同路径。也可以保留随机策略采样作为补充，但不能只依赖 PPO 训练早期的熵，因为熵衰减后路径可能塌缩。

路径模式维数、模式数和采样概率暂定，必须在阶段 1 训练前确定，并从阶段 1 一直保持到阶段 5。

### 3.3 多路径评估协议

1. 固定机器人初始关节状态和目标，除路径模式 `z` 或策略采样外关闭其他随机化。
2. 对每个 `z` 重复多次 rollout，保存 TCP 与关节轨迹、终局误差、速度和终止原因。
3. 对时间归一化轨迹使用离散 Fréchet 距离、DTW 或等价方法聚类。
4. 一个有效路径簇必须满足：簇内阶段成功率不低于 `70%`，且样本占比不低于 `10%`。
5. 两个路径簇暂以 TCP 轨迹最大横向分离不小于 `0.05 m`，或轨迹距离不小于起终点直线距离的 `10%` 作为区分参考；最终阈值由阶段 1 轨迹尺度复核。
6. 阶段 1/2 的暂定目标为至少 `3` 个有效几何路径簇；阶段 3 以后每个目标至少保留 `2` 个有效路径簇。若视觉传感器的多视角 RGB-D/实例分割结果与 USD 几何查询共同表明某目标只有单一可行拓扑通道，应按几何可行性修订，不用不可能的路径数阻塞课程。

## 4. 成功信号分层

课程同时记录两种成功，不得混用：

- **阶段成功 `curriculum_success`**：用于当前等级的能力统计和晋级，可以逐级收紧位置、姿态、速度、碰撞和多路径要求。
- **正式成功 `formal_parking_success`**：始终来自统一停车状态机。当前真值为位置误差不超过 `0.04 m`、姿态误差不超过 `10°`、TCP 线速度不超过 `0.03 m/s`，连续保持 `2` 个策略步，即 `0.5 s`，且没有安全失败。

最终成功奖励只能绑定 `formal_parking_success`。阶段成功可以作为课程统计或辅助里程碑，但不得写入正式评估成功率。

## 5. 碰撞分组与启用计划

碰撞配置拆分为 `C1/C2/C3` 三个阶段配置档，而不是在课程中累计同时启用三个独立组。阶段 1 和阶段 2 仅选择 C1，阶段 3 切换到 C2，阶段 4 切换到 C3，阶段 5 继续使用最终 C3。每个 episode 只能绑定一个碰撞配置档；C2/C3 内部是否包含前一级的具体碰撞 prim，由视觉传感器语义确认和 USD/CollisionAPI 查询共同确定。

| 碰撞配置档 | 视觉传感器空间语义 | 对应 USD prim/表达式 | 使用课程阶段 | 净空指标 | 状态 |
|---|---|---|---|---:|---|
| C1 | 玻璃防护结构 | `.../WorkStation/Glass/M_Glass` | 1、2 | P4/P7 标定 | 已冻结 |
| C2 | 工作站主体 | `.../WorkStation/WorkStation/M_WorkStation`，不含 C1 | 3 | P4/P7 标定 | 已冻结 |
| C3 | 最终完整工作站 | C1 与 C2 的并集 | 4、5 | P4/P7 标定 | 已冻结 |

### 5.1 视觉传感器辅助语义确认

空间语义不再依赖 viewport 截图，而是使用可复现的实际视觉传感器诊断管线：

1. 在独立诊断场景中配置固定外参的多视角 `CameraSensor`，至少覆盖工作站正面、侧面和俯视区域；相机配置、内参、外参和场景版本写入结果快照。
2. 同步读取 `rgb`、`distance_to_image_plane`、`instance_segmentation_fast` 和 `instance_id_segmentation_fast`；资产已有可靠语义标签时同时读取 `semantic_segmentation`，标签缺失时不得伪造语义结果。
3. 使用分割结果的 `info` 映射把像素实例反查到 USD prim；用深度、相机内参和外参恢复环境坐标系 `E` 下的可见点云、包围范围和遮挡关系。
4. 将多视角结果合并为“视觉实例/语义—prim 路径—空间范围”的候选表，用于判断各结构相对机器人、TCP 通道和目标的空间作用，并辅助提出 C1/C2/C3 分组。
5. 对每个候选 prim 再查询 USD 层级、变换、CollisionAPI 和碰撞启用状态。视觉传感器负责确认“看到了什么、在哪里、是否遮挡”，USD/CollisionAPI 负责确认“哪个 prim 真正参与物理碰撞”。
6. 输出结构化语义审计 JSON、相机标定、分割 ID 映射、点云范围和 C1/C2/C3 候选表。该管线默认不进入策略观测，正式非视觉训练关闭 CameraSensor，避免引入显存和渲染依赖。

机器人自身、地面、基座和必要支撑结构不进入可关闭障碍组；每组必须列出明确 prim，禁止关闭整座工作站碰撞。视觉结果不能替代 USD prim 与 CollisionAPI 的最终事实来源。

当前观测只有接触后的非法碰撞判定。若碰撞组位置或布局会随机化，需从阶段 1 预留碰撞前观测，例如各连杆到启用障碍组的最小距离、最近点向量或等价射线/深度表示；未启用组对应观测置零并附带启用掩码。

## 6. 五阶段课程配置与暂定成功指标

下表数值是第一版能力门槛，用于形成可执行训练方案；完成阶段 D 足量基线和对应阶段 smoke 后再按同口径数据修订。

| 阶段 | 场景与训练重点 | 阶段成功条件 | 统计目标 |
|---|---|---|---|
| 1：位置到达与多路径 | 固定同一起点和同一目标位置；路径模式 `z`；旋转动作受控；启用 C1 | `d_pos ≤ 0.08 m`，`v_tcp ≤ 0.08 m/s`，连续 `2` 个策略步；无 NaN、工作空间越界或已启用碰撞组安全失败 | 阶段成功率 `≥80%`；至少 `3` 个有效路径簇；各有效簇成功率 `≥70%`；关节限位/奇异保护异常终止率 `≤5%` |
| 2：位姿到达与多路径 | 相同物理起终点；释放旋转动作并加入姿态塑形；仍仅启用 C1 | `d_pos ≤ 0.06 m`，`e_rot ≤ 20°`，`v_tcp ≤ 0.06 m/s`，连续 `2` 个策略步；无安全失败 | 阶段成功率 `≥80%`；至少 `3` 个有效路径簇；阶段 1 位置回归成功率 `≥80%` |
| 3：任务内目标泛化 | 当前四个目标状态全部参与训练；保持路径模式；切换为 C2 | 每目标 `d_pos ≤ 0.05 m`，`e_rot ≤ 15°`，`v_tcp ≤ 0.05 m/s`，连续 `2` 个策略步；无安全失败 | 每目标成功率 `≥75%`，最差目标 `≥70%`；每目标至少 `2` 个有效路径簇；阶段 1/2 回归不下降超过 `10` 个百分点 |
| 4：完整碰撞避障 | 切换为 C3；完整目标分布；加入碰撞前净空观测和净空塑形 | 满足阶段 3 位姿条件，且 episode 全程无非法接触；净空阈值待视觉传感器管线与资产距离标定 | 每目标无碰撞成功率 `≥75%`；安全失败率 `≤5%`；超时率 `≤15%`；对存在多通道的目标至少保留 `2` 个有效路径簇 |
| 5：最终精确停靠 | 完整场景、完整目标、继续使用 C3；近端低速、姿态、dwell 和精度优化 | 使用正式成功：`d_pos ≤ 0.04 m`、`e_rot ≤ 10°`、`v_tcp ≤ 0.03 m/s`、连续 `2` 个策略步且无安全失败 | 总体正式成功率 `≥85%`，每目标 `≥80%`；安全失败率 `≤5%`；超时率 `≤10%`；见下述精度/准确度指标 |

### 6.1 阶段 5 精度与准确度

阶段 5 除成功率外分别统计准确度和精密度：

- 准确度：成功 episode 的终端位置误差中位数暂定不超过 `0.02 m`，P95 不超过 `0.04 m`；姿态误差中位数不超过 `5°`，P95 不超过 `10°`。
- 精密度/重复性：相同起点、目标和路径模式下重复 rollout，终端位置误差标准差暂定不超过 `0.01 m`，姿态误差标准差不超过 `2°`。
- 动态质量：成功时 TCP 速度必须不超过 `0.03 m/s`，并单独报告 dwell 内的最大速度和姿态波动。
- 安全质量：按目标分别报告非法接触、目标扰动、工作空间越界和超时，不能用总体平均掩盖单一目标失败。

若最终工程要求严于以上数值，应先修订本文和统一任务真值，再启动对应训练；不能只在阶段 5 临时改变正式成功定义。TCP 法兰偏置 `(0.0, -0.12, 0.102) m` 在精停靠训练前必须完成实测复核，否则标定误差会成为准确度上限。

## 7. 奖励与动作释放顺序

- 阶段 1：距离进展、历史最佳进展、邻近度、位置到达稳定性、路径模式覆盖；姿态项不驱动课程成功。
- 阶段 2：保留阶段 1 全部奖励，逐步加入姿态误差、工具轴对齐和位姿保持。
- 阶段 3：保持完整位置/姿态奖励，加入按目标均衡统计，避免高频目标支配梯度。
- 阶段 4：保留到达与姿态奖励，增加碰撞前净空进展；非法接触仍是硬安全失败，不用净空奖励替代。
- 阶段 5：完整启用低速进入、首次进入、dwell、最终成功和精度相关塑形；最终成功奖励仍只来自统一停车状态机。

各阶段奖励权重和动作掩码需要单独配置并随文档版本保存。升级时采用渐进权重或混合采样，避免单步突变。

## 8. 晋级、回退与回归门禁

暂时保留当前课程窗口规则：最近 `64` 个完整 episode，至少 `32` 个有效 episode 才判断；阶段成功率 `≥75%` 且安全失败率 `≤5%` 时允许晋级，阶段成功率 `<30%` 或安全失败率 `>20%` 时回退，切换后冷却 `32` 个完成 episode。

上述控制器门禁与第 6 节“阶段验收统计目标”职责不同：控制器门禁用于在线切换，阶段验收目标用于决定是否允许固化配置并进入下一轮长训练。每次升级还必须执行上一阶段固定回归集；若关键能力下降超过文档允许值，即使当前阶段成功率达到晋级线也不得通过人工验收。

## 9. 正式评估

- 关闭自动课程切换和训练随机化，冻结 PPO 与 `VecNormalize`。
- 按最终目标状态逐个固定评估，并按多个随机种子重复。
- 同时报告正式成功率、阶段成功率、位置/姿态误差分布、TCP 速度、完成时间、路径模式覆盖、非法接触、目标扰动、工作空间越界和超时。
- 多路径评估固定物理起终点，只改变路径模式；目标泛化评估单独改变目标，不把两种能力混在一个统计量中。
- 当前四个目标状态全部加入阶段 3 至阶段 5 的训练与逐目标评估；任务内泛化仍需通过按目标均衡统计和连续目标扰动等证据验证，不能仅凭四个离散目标宣称连续泛化。
